# Demo Sample Images

This directory contains clean, locally generated sample images demonstrating different orientations, formats, aspect ratios, and color transparency modes for testing **Simple Image Resizer**.

## Files Included

| Filename | Format | Dimensions | Mode | Description |
| :--- | :--- | :--- | :--- | :--- |
| `sample_landscape.jpg` | JPEG | 1600 × 900 | RGB (16:9) | Landscape orientation photo test with hills and sunset |
| `sample_portrait.jpg` | JPEG | 900 × 1600 | RGB (9:16) | Tall portrait orientation test |
| `sample_square.png` | PNG | 1000 × 1000 | RGB (1:1) | 1:1 square checkerboard graphic test |
| `sample_transparent.png`| PNG | 800 × 600 | RGBA (4:3) | Transparent alpha-channel test to verify transparency preservation |

All demo assets were generated locally without external downloads.
